# Sanggar Digital — extracted assets

Source: `img_97cb778d77de.png` (1536×1024 brand board).

- `crops/`: lossless PNG crops, retaining the original board background.
- `transparent/`: conservative border-connected background removal for logos, icons, mascot poses, silhouette, and ornament.
- `contact_sheet.jpg`: quick visual index.

Important: these are extracted raster assets, not clean vector masters. The source board is only 1536×1024, so use these for prototype/UI/mockup work. For production logo use, redraw/vectorize the emblem and wordmark from the brand specification.

Background removal is intentionally conservative. Inspect transparent PNGs for residual cream pixels or accidental holes, especially mascot hair/ribbons and the main emblem. The merchandise, phone mockups, and complex decorative graphics remain crop-only because their backgrounds contain shadows, texture, or photography.
